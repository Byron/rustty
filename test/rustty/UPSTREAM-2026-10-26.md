# Ghostty main update: 2026-10-26

Reviewed `a2e440396403385680008e456a741a7776091412..87b65966dfadc42dacd8d55b99ebc430e6a52455`:
**166 commits, comprising 132 non-merge commits and 34 merges**. The Tix stack was
updated onto the latter local `main`; `a44a50f5b` is the restored Rustty tip before

## Existing equivalents and absent operations

| Change | Rustty disposition |
| --- | --- |
| Mouse-button state bounds | Already safe: Rustty stores `Option<MouseButton>` rather than indexing a click-state array by enum value. Its explicit encoder rejects unsupported extra buttons. |
| IME candidate positioning | Already covered: preedit/focus changes request repaint; the native candidate area uses the rendered preedit caret or full cursor-cell rectangle, converting physical pixels to logical coordinates once. |
| Progress pulse removal | Already covered: removal clears both progress and deadline, and painting only schedules animation for visible indeterminate progress. Rustty has no persistent GTK tick callback. |
| Cross-tree split transfer focus | No corresponding local cross-window pane-transfer UI. Existing close logic selects a remaining nearby pane and clears stale zoom/focus references. |
| Initialization failure cleanup | Already covered by Rust ownership/RAII for config, fonts and renderer resources, and existing PTY child/worker cleanup. No corresponding manual double-free or leaked retain was found. |
| Malformed OSC 7501 identifiers | No OSC 7501 parser/event exists in Rustty. Its separate OSC 777 status protocol is unaffected; this validation fix does not add the missing protocol. |
| Snapshot grid SIMD overwrite | No equivalent unsafe vector-pointer store: Rustty writes snapshot grids through checked scalar/slice operations. |

The existing IME tests cover search/terminal focus, title popups and multilingual
preedit caret placement. Progress tests cover removal, expiry, exit and animation
scheduling. Session tests exercise exec failure, child reaping, shutdown of a child
that ignores hangup, and draining final output. These paths already implement the
relevant behavior without Ghostty's GTK callbacks or manual resource management.

## Final integration verification

All non-ignored Rust workspace library/integration tests and the app library/binary
unit suites passed across the completed runs: **1,252 tests**, with **246 existing
ignored fixtures**. Documentation tests also passed. The initial broad run found a
tab assertion that expected CUB to cross the left margin; its corrected expectation
was amended into the original cursor fix and checked there before replaying the
remaining ports. A macOS watchdog-start readiness EOF failed one native retention
fixture before terminal work began; both its isolated rerun and all 15 tests in
that suite passed. The exact transient OS cause was not established.

`cargo +1.95.0 fmt --all -- --check` and production workspace Clippy
(`--workspace --lib --bins -- -D warnings`) passed. Cargo commands used
`--offline --locked`; the app's interactive native integration executables were
excluded. No code changed after these checks except the tab test expectation.

Final focused native comparisons passed without differences:

- 3,703 snapshot-wire comparisons, including live streamed restores.
- 1,452 placeholder and 309 animation comparisons.
- 6 raw APC-parser comparisons.
- 69 separately checked Kitty cross-decode/READY/progress/live-upload comparisons.

The broad parity sweeps still expose older gaps outside the 166-commit range:

- Saved-cursor resize uses a stale prior-row column in Rustty, producing column 4
  where native produces 5. Native fix `afded91dfa` predates the old base; the Rust
  resize implementation is unchanged by this update.
- Rustty accepts the numeric separator in OSC `9;4;1;1_0`; native rejects it via
  older fix `73768913b`. Both progress parsers are unchanged in this range.
- The native raw-parser observer synthesizes OSC events for CAN/SUB cancellation.
  Both production parsers discard them, but the older observation helper reports
  two extra events in `parser/osc-cancel`. This limits that harness comparison.

These are recorded rather than included in the current upstream-port scope. No
complete cross-engine parity or measured performance improvement is claimed.

Tix has no pending rebase, local `main` at `87b65966d` is an ancestor, and all 161
original Rustty commits and the `rustty-windows` fork remain represented. The fork
is `b4579ec09` (change `nxtvulyql`). Remote refs, unrelated branches, tags, the stash,
and the existing StGit stack ref are unchanged. No push was performed.
