## Mainline dispositions

| Area | Disposition and evidence |
| --- | --- |
| Kitty clipboard and confirmation | OSC 5522 parsing, bounded transfers, aliases, acknowledgements, session grants, and native MIME access already exist in `rustty-vt/src/clipboard/kitty.rs`, `rustty/src/session.rs`, and both native hosts. Ported the missing representation previews. The GTK denial crash depends on manual request-tag handling and a remember checkbox; Rustty uses enums and grants only on successful approval. Its denial button never remembers access. Clipboard protocol comparisons and preview tests pass. The upstream multipart test's acknowledgement wait is inherited; the Rust comparison transport already waits for each reply. |
| Erased history pins | `Screen::discard_row` invalidates tracked points and selections by stable row ID instead of moving erased handles onto live rows. A new regression proves erased history handles become invalid while active handles retain identity. |
| Scroll-clear cursor resources | Rustty's existing page/resource ownership and synchronization preserve styles and hyperlinks when their original page is pruned. A new test forces page deletion and checks reference counts before and after printing. No runtime port was needed. |
| Capacity narrowing | Ported the row cap in `PageCapacity::adjust_columns`. Both adapters now call the corrected behavior; the native adapter's duplicated old guard had initially hidden mainline's fix. Capped rows retain metadata and fit within the original allocation. |
| Terminal and tmux dimensions | Rustty construction intentionally clamps dimensions to one cell; resize and binary snapshot decoding validate dimensions. `tmuxx-layout` already bounds legacy and JSON pane geometry before application, with a stricter 10,000-cell limit. New zero/oversized pane regressions pass in both formats. The native snapshot error mapping is Zig-specific; both decoders already reject zero dimensions. |
| Shell directory escape injection | Inherited the Bash and Zsh fixes in the source scripts bundled by both Rustty build recipes. Four live shell checks using test-owned directories reject raw ESC/BEL and backslash-encoded clipboard sequence injection. |
| SSH SetEnv preservation | Rustty's system SSH helper invokes `ssh -T` without replacing `SetEnv`; native tmuxx sessions establish their own terminal environment. Existing helper tests preserve configured authentication environment and explicit askpass policy. Ghostty's separate `+ssh` TERM option fix is inherited. |
| Split zoom indicator | Rustty's existing close/normalization logic clears stale pane and quadrant zoom state when the relevant split disappears. Workspace and presentation tests pass. |
| AppKit titlebar-tab movement | Rustty draws its own tabs and reorders the existing workspace; it does not remove/reinsert AppKit tab-group windows. The neighbor-flash fix is inherited in Ghostty and has no matching Rustty operation. |
| AppleScript name override | Inherited in Ghostty. Rustty has no AppleScript object hierarchy or scripting dictionary to extend; its existing editable tab/panel names do not provide this AppleScript API. No AppleScript parity is claimed. |
| Fontconfig language handling | Inherited in Ghostty. The shipped Rustty hosts use Core Text or the Windows font path and do not consume Fontconfig's lang/langset union. |
| FreeBSD allocation and libghostty CI | Inherited the native FreeBSD fixes and CI/build changes. Rustty uses Rust-owned storage rather than Zig's memory decommit/recommit layer and has no shipped FreeBSD desktop host. The updated native reference oracle builds on macOS; FreeBSD execution was not tested. |
| NSPasteboard coverage | Inherited the Ghostty tests. Rustty's existing native test passed text/binary MIME roundtrips, aliases, listings, invalid-write preservation, clear behavior, and unsupported primary selection on a uniquely named pasteboard. The upstream tests also exercise older opinionated file-URL conversion behavior; that is not a newly added runtime feature in this range, and no full clipboard-conversion parity is claimed. |
| Dependencies, packaging, CI, translations, version and metadata | Inherited z2d/dependency mirrors, Golden Gate/Xcode CI, Snap/Flatpak repairs, Zig 0.17 example declarations, Irish/Polish catalogs, Ghostty version changes, and VOUCHED metadata. Rustty's Rust/WGPU renderer, macOS/Windows bundles, version, and UI do not consume the corresponding GTK/Zig implementations. |
| Unicode escapes and truncated configuration UTF-8 | Rustty already uses checked radix arithmetic, `char::from_u32`, `str::chars`, and whole-file UTF-8 validation before applying configuration. New regressions cover lowercase/uppercase hex overflow, valid mixed-case hex, and all truncated 2–4-byte UTF-8 tails after a valid prefix. |

## Performance and validation

No upstream benchmark source or workload was added or changed in this range.
The native allocation change prevents an erroneous failure; no throughput or GUI
speedup is claimed. Clipboard previews decode once per selected representation
and retain a bounded thumbnail rather than decoding on each redraw.

Cargo used Rust **1.95.0**, `--locked --offline`, and existing caches. The native
oracle used the official Zig **0.17.0** macOS ARM64 archive, whose SHA-256 matched
the official release index, with `vt-oracle -Demit-lib-vt=true
-Demit-macos-app=false -Doptimize=safe`.

- All workspace library and binary suites passed: **924 tests**, **6 existing
  ignored tests**. Their Rust production/test sources match the final tree.
- All **10 capacity**, **20 screen**, **68 configuration**, and **10 layout**
  focused tests passed. The capacity regression was observed failing before the
  fix. The equivalent-behavior regressions passed without runtime changes.
- All **4 clipboard preview tests** passed, including alpha, malformed/oversized
  images, UTF-8 truncation, representation switching, texture reuse, and unchanged
  transfer payloads.
- The explicitly selected native named-pasteboard test passed without touching
  the user's general or selection clipboard.
- **338 capacity**, **2,670 OSC 52**, **816 Kitty clipboard**, and **3,703
  snapshot-wire** native/Rust comparisons passed without differences.
- Both terminal benchmark suites passed **111 correctness checks**.
- Python harness checks passed **13 tests**, with **12 existing skips**. All
  **12 frozen groups** retain coverage and match current source checksums.
- Rust formatting, Zig adapter formatting, and diff whitespace checks passed.
  Production workspace Clippy passed with only the existing `nonminimal_bool`
  lint allowed. Strict Clippy reproduced that pre-existing expression in
  `desktop.rs`'s smoke-window setup; it was not changed by this task.
- The bundled skill-creator validator accepts `tix-reintegrate`.

The unfiltered snapshot/page sweeps also reproduced the saved-cursor resize
mismatch already documented in [the October 26 audit](UPSTREAM-2026-10-26.md):
Rustty reports column 4 where native reports 5. Its introducing upstream fix
predates this range. The three delivery variants fail identically. Earlier
progress-number and raw-parser observer gaps from that audit were not retested.
This integration does not establish complete cross-engine parity.

Interactive macOS UI and Windows runtime behavior were not exercised. Native
pasteboard and headless egui checks cover the changed clipboard paths; they do
not substitute for interactive testing.
