## Behavior and application evidence

**Terminal behavior.** DECIC/DECDC and DECBI/DECFI now use shared horizontal shifts with correct margins, wide cells, combining text, styles, links and backgrounds. Scalar/grapheme printing recomputes the right boundary after wrapping; the redundant ASCII fallback gate was removed. VT export reconstructs pending wrap at the effective horizontal margin. Blank rows retain a line selection during a drag in either direction. These changes have focused failures observed on the prior implementation and fresh native comparisons after the fixes.

**Kitty graphics.** Unicode placeholders select virtual placements only. Image-number lookup and local eviction use stable transmission identity, so animation and frame switching cannot make an older image appear newer. Eviction removes the affected placements. The exact no-history resize/image-placement case already retained a live Rust cursor row and passed a fresh comparison; that source guarantee required coverage rather than a runtime change. Existing tmux attach-quota usage ordering was preserved because it is a separate policy.

**Tmux control and typed interfaces.** The Rust byte-slice decoder already validates full `u64` IDs, preserves arbitrary output, handles omitted/empty output and exit messages, and routes active-window updates to the correct session. Fragmented maximum/overflow ID cases and client routing regressions now protect those guarantees. Empty parser continuation, wrapping search selection, initialized query callbacks, length-bearing text/pixels and combined graphics layers already exist through Rust types and current callers. The C ABI additions do not require rebuilding foreign pointer/size conventions in these APIs.

**Commands and working directories.** Repeated literal spaces in `direct:` commands no longer produce empty arguments; embedded tabs and shell command text keep their existing meaning. Empty prefixed commands were already rejected. OSC 7 authorities are decoded before local-host matching and Windows UNC interpretation; malformed escapes, invalid UTF-8, NUL and foreign-host checks remain in their existing admission paths. **Themes and appearance.** The independent Rustty theme copy was refreshed from `ghostty-themes-release-20261026-153024-27cbbb5.tgz`: 42 additions, 5 updates and 861 total themes. ### Independent hyperlink cell-map capacity

`68f851eb2` / `nokoswn` (measured as `cbfb73cef`) separates the linked-cell map from the distinct-link set. Map exhaustion grows only the map. Typed/layout PageCapacity requests default `hyperlink_cells` to 64 independently of set bytes, accept explicit zero, and do not clamp ordinary layouts to page dimensions. Copying, reflow, resource admission and exact range accounting use the new dimension. The d20 HyperlinkMap benchmark delta only switches its existing capacity setup from `hyperlink_bytes=entries/16×Item` to `hyperlink_cells=entries`; it adds no operation or input. Shared native setup is inherited, while independent layout and terminal consumers are ported and measured. The new synthetic link workload comes from d039.

GHOSTSNP stays at version 1 and retains its u16 capacity hint: `max(set_bytes, ceil(map_cells/16)×48)`, saturated at 65535. Hints **65520–65535** decode to enough cells for the page, capped at 65535. Full and compact Page JSON preserve their legacy six-field capacity shape through the same combined hint; the page-context adapter accepts an explicit independent field when present, while direct typed/layout requests keep the independent default of 64. Older zero or undersized hints retain the existing bounded resource-growth behavior during restoration. The install-cell boolean selects ordinary versus reflow copying; it does not disable growth.

Old binaries can parse the preserved shapes but cannot restore newly supported dense pages above their old **26,214 usable linked-cell ceiling**, including saturated 65520–65535 hints. This is compatible framing with a content-capacity limit, not universal bidirectional restoration. Restored capacity can conservatively exceed the live source because the legacy format has one shared hint.

The 200-cell, one-URL regression failed before: distinct-link bytes grew from 192 to 384. They now remain 192. All 218 VT library tests, 83 affected integration tests and 25 tmux snapshot tests passed. Native comparisons passed all **386 raw layout cases**, 181 smoke cases and 669 fresh hyperlink snapshot cases, including 200×150 dense pages and the 65519/65520/65535 boundary. These raw layout results supersede the style stage's temporary projection.

Both engines now pass the **8,192-record fully linked mixed-history check**, before and after 128→64→128 reflow; its former opt-in expected-failure status was removed.
